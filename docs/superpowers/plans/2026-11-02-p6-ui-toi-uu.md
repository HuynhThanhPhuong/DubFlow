## Review Focus
1. **Fullscreen exit:** every part of the editor layout is restored, at 1280 px and 375 px, whether you leave with Esc or the button.
2. **Page input:** typing an out-of-range, empty or non-number page clamps or ignores the value; it never shows an empty list.
3. **Logo overlay:**
   - coordinates are stored in source-video pixels (or fractions) and survive letterboxing;
   - render places it at the same spot as the preview;
   - a missing or deleted image file gives a clear Vietnamese error, not a crash.
4. **Speedups:** output pixels and audio stay equivalent. Compare frames and audio duration before and after, and do not just trust timing.
5. **Early export check:** a blocked job fails within seconds, with the same Vietnamese message as today.

### Task 2: Logo overlay — backend
**Files:** `backend/dubflow/app.py`, `schemas.py`, `store.py` or the data dir layout, `pipeline.py` (render), `preferences.py`, and tests.
- **Logo library:**
  - `POST /api/logos` uploads PNG/JPEG/WebP, ≤ 5 MB, ≤ 4096 px, re-encoded to PNG with alpha;
  - stored as `data/logos/<sha256>.png` (dedupe);
  - `GET /api/logos` lists `{id, name, width, height, url}`;
  - `GET /api/logos/{id}/image`;
  - `DELETE /api/logos/{id}` refuses (409, Vietnamese message) while a job still uses it.
- **Per-job overlays:**
  - stored in `job.json` as `overlays: [{id, logo_id, x, y, width, height, opacity 0..1, start, end}]`, in source-video pixels;
  - start/end default to the whole video;
  - `PUT /api/jobs/{id}/overlays`, validated: the box is clamped inside the frame, and the logo exists.
  - Changing overlays invalidates the exported output, but not the erase/clean cache.
- **Default for new jobs:**
  - preference `default_overlay: {logo_id, fx, fy, fw, opacity}` holds fractions of the frame, with the height from the logo's aspect ratio;
  - on job creation, once the size is known, it adds one overlay.
- **Render:**
  - an ffmpeg `overlay` of each logo (scaled to w×h, `colorchannelmixer=aa=opacity`, `enable=between(t,start,end)`) placed after subtitle burn-in, so the logo is on top;
  - a missing logo file raises NeedsReview with a Vietnamese message.
- **Tests:** upload validation and dedupe, list/delete-in-use, PUT clamp, the default overlay applied to a new job, the render filter contains the overlay at the right coords, and a missing file gives NeedsReview.

### Task 3: Logo overlay — frontend
**Files:** `Player.tsx`, a new `LogoOverlay.tsx` (reuse `regionGeometry.ts` toDisplay/fromDisplay), `api.ts`/`types.ts`, a small panel in the region/tools area, and tests.
- **Flow:**
  1. "Chèn logo" button near "Vẽ vùng che".
  2. A popover shows the library thumbnails plus "Tải logo lên".
  3. Picking one places it top-right with a margin of 3% of the width, at 15% of the video width.
  4. It appears as an image on the player (real preview at the chosen opacity). Drag to move, corner to resize (aspect locked; Shift frees it).
  5. When selected, a toolbar below the player shows an opacity slider, Từ/Đến times (default the whole video), "Xóa logo" and a checkbox "Tự chèn cho video mới". The checkbox saves `default_overlay` from the current box as fractions.
- Saves through `PUT /api/jobs/{id}/overlays`, debounced, and reverts on error, as RegionOverlay does.
- Disabled while the job is running.
- **Tests:** placing a logo stores source pixels under letterboxing, drag and resize update the box, the opacity slider updates the preview, and the default checkbox calls preferences.

### Task 5: Render/export speed
**Files:** `backend/dubflow/pipeline.py` (render, about line 940–1050), `subtitle_mask.py`, `review.py`, `engine_cli.py` (erase), and tests.
- **Export gate first:** run `review.require_export` before erase/OCR/encode in render.
- **OCR noise:**
  - transient regions that are both very short (< 0.5 s) and ≤ 2 characters are not flagged as a `SCREEN_TEXT_UNTRANSLATED` error;
  - downgrade them to review severity, or auto-skip with a note.
- **Transient mask filter:**
  - today 91 overlay/delogo/blur/dilation chains run on every frame (`enable=` gates only the overlay);
  - restructure so the work is only done inside each region's time window. For example: trim and segment the processing per window and overlay with an offset, render the transient masks into clean.mp4 through the same LaMa or frame path, or group regions by time.
  - Measure on `tmp/p6` copies of the P5 TM job (106 s, 1207 s render now) and dub2 (60 s).
- **Encode:**
  - use NVENC (`h264_nvenc`) when ffmpeg and the GPU support it, with a quality comparable to libx264 crf 20;
  - fall back to libx264.
  - Probe once per run.
- Report a before/after table per step, and compare frames (PSNR or SSIM ≥ 35 dB on 5 sampled frames versus the current output).
