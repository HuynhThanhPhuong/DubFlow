# P3 — Dịch qua API (Gemini trước) + chế độ thủ công — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thay luồng dịch local (Ollama/seq2seq) bằng dịch qua API (Gemini làm và test thật trước, OpenAI/Anthropic cùng interface), tiết kiệm request, có giới hạn hạn mức gói miễn phí và kiểm soát chi phí gói trả phí; thêm chế độ thủ công xuất SRT Trung + lệnh mẫu và nhập SRT Việt theo số thứ tự.

**Architecture:** Module mới `translate_api.py` (provider HTTP thuần, dùng `httpx` đã có) và `translate_job.py` (chia phần, prompt theo chế độ, kiểm tra, gửi lại một lần, cache, giới hạn tốc độ, chi phí, log). Bước dịch chạy trong tiến trình worker, không qua `engine_cli`. Xóa nhánh local/ollama và dọn model local.

**Tech Stack:** Python 3 / FastAPI / httpx 0.28.1 / SQLite store; React + TS + Vite + vitest.

**Spec:** `docs/superpowers/specs/2026-11-01-dubflow-web-v2-design.md` — mục 6.4 (dịch), 6.7 (Cài đặt), 6.8 (dọn), 8 (kiểm chứng 6.4).

## Global Constraints

- Web không bao giờ gọi API khi chưa có key; chưa có key → chế độ thủ công, không báo lỗi chặn (spec 3, 5).
- Key chỉ lưu trên máy (store `settings/main`), GET Cài đặt không trả key (giữ cơ chế `public_preferences` + `has_api_key`), không ghi key vào file, log, `translation-runs`, thông báo lỗi.
- Video ≤ 10 phút: đúng **1 request** khi không có lỗi (spec 8).
- Câu lỗi gom lại gửi lại **một lần** trong một request; không dịch lại cả video vì vài câu lỗi (anti-goal).
- Hạn mức RPM/RPD, đơn giá, mức trần chi phí, CPS Vietsub: đặt trong Cài đặt, không viết cứng trong code (chỉ giá trị mặc định ở `preferences.py`).
- Tên model không viết cứng làm danh sách; Cài đặt có nút tải danh sách model từ API của provider.
- Đổi chế độ đầu ra sau khi đã dịch: không tự gọi lại; chỉ dịch khi người dùng bấm.
- Không đụng `repo-tests/ollama-storage`, `D:\OmniVoice`, `bench/runs`. Dọn dẹp: chuyển vào Thùng rác, không xóa vĩnh viễn.
- Giữ kiểu xuống dòng (CRLF/LF) của từng file. Test backend: từ `backend/`, `$env:PYTHONIOENCODING='utf-8'; .venv\Scripts\python.exe -m unittest discover -s tests`. Frontend: `npm test`, `npx tsc --noEmit` trong `frontend/`.
- Thông báo cho người dùng bằng tiếng Việt.

## Review Focus

1. **Hết hạn mức ngày giữa chừng** (video dài nhiều phần): các phần đã dịch phải được giữ, job ở trạng thái tạm dừng có lời nhắn rõ, bấm "Dịch tiếp" chỉ gửi phần còn thiếu → test ở Task 2 và Task 3.
2. **Model trả JSON cụt (`finishReason` MAX_TOKENS) hoặc thiếu/trùng id** → không ghi đè lời đã có, gom câu lỗi gửi lại một lần, vẫn lỗi thì để trống + cờ → test Task 2.
3. **Người dùng đã sửa tay lời Việt rồi bấm dịch** → không ghi đè câu đã có lời (chỉ dịch câu trống), trừ khi chọn "Dịch lại tất cả" → test Task 3.
4. **SRT Việt nhập vào lệch số câu, thiếu số, có dòng trống, có BOM/CRLF, số thứ tự nhảy** → báo lỗi rõ, không ghi gì; thời gian luôn lấy bản gốc → test Task 4.
5. **Key sai / mạng lỗi / 5xx** → lỗi dễ hiểu tiếng Việt, không lộ key, job không kẹt ở trạng thái đang chạy → test Task 1 và Task 3.

### Task 1: Lớp provider HTTP (`translate_api.py`)

**Files:**
- Create: `backend/dubflow/translate_api.py`
- Test: `backend/tests/test_translate_api.py`

**Interfaces:**
- Produces:
  - `class ProviderError(Exception)` — thông điệp tiếng Việt, không chứa key.
  - `class RateLimited(ProviderError)` với `retry_after: float | None`.
  - `class QuotaExhausted(ProviderError)` (hết hạn mức ngày).
  - `@dataclass Usage(input_tokens:int, output_tokens:int, thinking_tokens:int=0)`.
  - `@dataclass Reply(data: dict | None, text: str, truncated: bool, usage: Usage)`.
  - `class Provider(Protocol)`: `name: str`; `generate(system: str, user: str, schema: dict, max_output_tokens: int) -> Reply`; `list_models() -> list[str]`.
  - `make_provider(name: str, key: str, model: str, *, thinking: str = 'default', base_url: str | None = None, client: httpx.Client | None = None) -> Provider`; `name` ∈ `'gemini' | 'openai' | 'anthropic'`.

**Shape từng provider (phải đúng):**
- **Gemini:** `POST {base or https://generativelanguage.googleapis.com}/v1beta/models/{model}:generateContent`, header `x-goog-api-key`. Body: `systemInstruction.parts[0].text`, `contents=[{role:'user',parts:[{text:user}]}]`, `generationConfig={responseMimeType:'application/json', responseJsonSchema:schema, temperature:0.3, maxOutputTokens}`. `thinking`: model bắt đầu `gemini-3` → `thinkingConfig.thinkingLevel` = `'low'|'high'`; model khác → `thinkingBudget` (`low`=1024, `high`=-1); `'default'` → không gửi `thinkingConfig`. Đọc `candidates[0].content.parts[*].text` (bỏ part có `thought: true`), `finishReason` (`MAX_TOKENS` → `truncated=True`), `usageMetadata.promptTokenCount/candidatesTokenCount/thoughtsTokenCount`. 429: đọc `error.details[]` — `RetryInfo.retryDelay` ("37s") → `retry_after`; `QuotaFailure.violations[].quotaId` chứa `PerDay` → `QuotaExhausted`, ngược lại `RateLimited`. 400/401/403 → `ProviderError('Key Gemini không hợp lệ hoặc không có quyền dùng model …')`. `list_models`: `GET /v1beta/models?pageSize=1000`, giữ model có `generateContent` trong `supportedGenerationMethods`, bỏ tiền tố `models/`.
- **OpenAI:** `POST https://api.openai.com/v1/chat/completions`, `Authorization: Bearer`, `response_format={type:'json_schema', json_schema:{name:'dubflow_translation', schema, strict:false}}`, `max_completion_tokens`; `finish_reason=='length'` → truncated; usage `prompt_tokens/completion_tokens`. 429 có `Retry-After` header; `insufficient_quota` → `QuotaExhausted`. `list_models`: `GET /v1/models`.
- **Anthropic:** `POST https://api.anthropic.com/v1/messages`, headers `x-api-key`, `anthropic-version: 2023-06-01`; JSON có cấu trúc bằng một tool `submit_translation` với `input_schema=schema` và `tool_choice={type:'tool',name:'submit_translation'}`; đọc `content[]` block `tool_use.input`; `stop_reason=='max_tokens'` → truncated; usage `input_tokens/output_tokens`; 429 `retry-after` header. `list_models`: `GET /v1/models`.
- OpenAI và Anthropic chỉ test bằng HTTP giả (spec: Gemini làm và test thật trước). Ghi rõ trong docstring.

### Task 2: Điều phối dịch (`translate_job.py`)

**Files:**
- Create: `backend/dubflow/translate_job.py`
- Test: `backend/tests/test_translate_job.py`

**Interfaces:**
- Consumes: `make_provider`, `Reply`, `Usage`, `RateLimited`, `QuotaExhausted`, `ProviderError` (Task 1).
- Produces:
  - `PROMPT_VERSION = 'p3-1'`.
  - `@dataclass Item(id: str, zh: str, start: float, end: float, speaker: str, kind: str)` — `kind` ∈ `'cue' | 'onscreen'` (region transient cần dịch).
  - `@dataclass Plan(chunks: list[list[Item]], requests: int, input_tokens: int, output_tokens: int, cost_usd: float | None)`.
  - `plan_translation(items, mode, prefs) -> Plan` — chỉ ước tính, không gọi mạng.
  - `@dataclass Outcome(texts: dict[str,str], failed: list[str], context: dict, requests: int, usage: Usage, cost_usd: float | None, paused: str | None)` — `paused` ∈ `None | 'quota' | 'cost_cap'`.
  - `run_translation(directory: Path, items, mode, prefs, provider, *, limiter, terminology: str = '', allow_over_cap: bool = False, sleep=time.sleep) -> Outcome`.
  - `class RateLimiter(path: Path, rpm: int, rpd: int, now=time.time)`: `acquire()` chờ đủ RPM (gọi `sleep`), raise `QuotaExhausted` khi đếm ngày ≥ RPD; lưu đếm vào `path` (JSON, theo `provider/model`, ngày tính theo giờ Thái Bình Dương: `zoneinfo('America/Los_Angeles')` nếu có, không có thì UTC−8). Bộ đếm cục bộ chỉ là tư vấn; 429 từ server là chuẩn.

**Quyết định (người viết plan):**
- **Ước tính token:** đầu vào = `ceil(len(json_payload_utf8_chars) / 1.5)` cho phần chữ Hán + phần prompt hệ thống tính `len/4`; đầu ra = `sum(max(12, 2.2 * len(zh)))` + 12/câu cho id và JSON. Hằng số đặt ở đầu module, có comment.
- **Chia phần:** cả video là 1 phần nếu ước tính đầu ra ≤ `0.6 * prefs.max_output_tokens` và đầu vào ≤ `prefs.max_input_tokens`. Nếu không, chia thành **ít phần nhất** có thể; ranh giới chọn ở khoảng lặng lớn nhất (khoảng trống giữa `end` câu trước và `start` câu sau) trong vùng ±15% quanh điểm chia đều. Chia tất định (cùng input → cùng phần).
- **Prompt:** `system` cố định theo `mode` (tiếng Việt):
  - `vietsub`: ngắn gọn, đọc kịp, tối đa `prefs.vietsub_cps` ký tự/giây theo thời lượng câu (truyền `max_chars` cho từng câu).
  - `tm`: lời đọc tự nhiên một giọng, độ dài khớp thời lượng: truyền `target_syllables ≈ duration * 4.5` mỗi câu.
  - `dub`: như `tm` và giữ giọng điệu, xưng hô theo nhân vật (`speaker`).
  - Chung: dịch sát nghĩa, tự nhiên, không thêm chú thích; `onscreen` là chữ trên hình, dịch ngắn.
  - `user` = JSON `{video_title?, terminology, context (bảng tích lũy), items:[{id, zh, dur, speaker, kind, max_chars|target_syllables}]}`.
- **Schema trả về:** `{context:{characters:[{name, zh, gender?, note}], address:[{from, to, xung, ho}], glossary:[{zh, vi}]}, items:[{id, vi}]}`.
- **Kiểm tra:** thiếu id, id lạ, trùng id, `vi` rỗng, hoặc `truncated` → các id đó vào nhóm lỗi; id lạ bỏ qua. Không ghi đè lời có sẵn bằng kết quả lỗi.
- **Gửi lại:** sau khi chạy hết các phần, nếu có câu lỗi → **một** request duy nhất cho tất cả câu lỗi (kèm bảng ngữ cảnh). Vẫn lỗi → `failed`.
- **Ngữ cảnh:** bảng `context` của phần trước gộp vào phần sau (gộp theo khóa `zh`/`name`, phần sau ghi đè). Lưu `translation-context.json`.
- **Cache:** mỗi phần một khóa `sha256(PROMPT_VERSION, provider, model, mode, terminology, json(items của phần))` → `translation-cache-v2.json` lưu `{key: {items, context}}`. Phần đã có cache thì không gọi API. Cache cũ (`translation-cache.json`, `translation-scene-cache.json`) bỏ qua.
- **Hạn mức:** trước mỗi request gọi `limiter.acquire()`. `RateLimited` → chờ `retry_after` (không có thì backoff 10 s, 30 s, 60 s) rồi thử lại tối đa 3 lần cho request đó. `QuotaExhausted` → dừng, `paused='quota'`, giữ các phần đã xong (đã ở cache).
- **Chi phí:** khi `prefs.tier=='paid'`: `cost = in*price_in/1e6 + out*price_out/1e6` dùng usage thật. Trước mỗi phần, nếu `spent + ước tính phần này > prefs.cost_cap_usd` và `not allow_over_cap` → `paused='cost_cap'`. `tier=='free'` → `cost_usd=None`, không áp trần.
- **Log:** mỗi lần chạy ghi `translation-runs/<UTC yyyymmdd-HHMMSS>.json`: provider, model, mode, prompt_version, số phần, số request, usage từng request, chi phí, id lỗi, lý do dừng. Không ghi key, không ghi prompt đầy đủ.

  - Job JSON thêm `translation_usage`: `{requests, input_tokens, output_tokens, cost_usd|null, provider, model, mode, at}` cộng dồn theo job (lưu `translation-usage.json` trong thư mục job).
  - `prepare`: khi còn câu trống — **không** tự gọi API nữa; luôn `NeedsReview` với thông điệp hiện có (người dùng bấm dịch hoặc làm thủ công). Bỏ `auto_translate`.
