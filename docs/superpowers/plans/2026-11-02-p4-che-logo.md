# P4 Che logo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Detect logos and fixed text automatically and pre-box them so the user only ticks ✓ or ✗. The user can drag a box on the video to add anything that was missed. Erase both kinds with the same eraser as the subtitles (LaMa, 6.2). Remove the px input boxes.

**Architecture:**
- **Detector.** A new pure-numpy module `logo_detect.py` samples frames sparsely and finds edges that persist on a changing background.
  - It merges these with the OCR "static" fragments, which today come out as hundreds of pieces, into a few candidate regions.
  - It runs as engine stage `logos` (OCR venv) after OCR in prepare, and again on demand.
- **Eraser.** The erase stage (`engine_cli.erase`) also erases enabled static regions over their time range.
  - `clean.mp4` then has subtitles and logos removed.
  - Render and preview skip the regions that are already erased.
- **Frontend.** The Player gets an overlay with dashed candidate boxes (✓/✗), a "Vẽ vùng che" draw mode with drag and corner resize, and letterbox-aware coordinate mapping.

**Tech Stack:**
- FastAPI and Python, with numpy and cv2 in the OCR venv `repo-tests/ocr`.
- React 18, TypeScript and vitest.

**Spec:** `docs/superpowers/specs/2026-11-01-dubflow-web-v2-design.md` §2 G8, §6.6, §6.7 (bullet 2), §8 (6.6)

## Region schema additions (shared by all tasks)
`Region` (backend `schemas.py`, frontend `types.ts`) gains optional fields:
- `auto: bool = False`: created by the detector.
- `confirmed: bool = False`: the user ticked ✓. Drawn boxes are created `auto=False, confirmed=True`.
- `label: str = ''`: a short display label. The detector sets `"Logo"` or `"Chữ cố định"`.

Kinds:
- Detector candidates and drawn boxes use `kind='static'`.
- An unconfirmed auto candidate is `enabled=True`, so it is pre-ticked.
- ✗ sets `enabled=False` and `confirmed=True`, so a re-run of detection does not resurrect a rejected box.
- ✓ sets `enabled=True` and `confirmed=True`.

## Review Focus
1. A static camera shot (whole background still) must not turn into a giant "logo". Require the background ring around a candidate to change.
2. A logo that appears only part of the video gets its real time range, not 0 → duration.
3. Re-running detection keeps the user's ✓/✗ decisions and drawn boxes. It only replaces unconfirmed auto candidates.
4. Changing or ticking a static region makes `clean.mp4` stale. Render must not ship a stale erase or leave the logo unmasked.
5. Drawing on a letterboxed/pillarboxed player, or in a narrow window, must map to correct source pixels.

### Task 1: Logo detector + candidate merge (backend)

**Files:**
- Create: `backend/dubflow/logo_detect.py`, `backend/tests/test_logo_detect.py`
- Modify: `backend/dubflow/engine_cli.py` (new stage `logos`), `backend/dubflow/pipeline.py` (run after OCR in prepare), `backend/dubflow/schemas.py` (fields above), `backend/dubflow/app.py` (POST `/api/jobs/{id}/detect-logos`, JSON body required, same pattern as `/translate`: enqueue a task, 409 if job busy)

**Interfaces (produces):**
- `detect_static(frames: list[np.ndarray], times: list[float], duration: float, exclude: list[tuple[int,int,int,int]], scale: float) -> list[dict]`
  - `frames` are grayscale, downscaled. `exclude` boxes are in source px.
  - Returns region dicts in source px: `x,y,width,height,start,end`, plus `presence` (fraction of samples present).
- `merge_candidates(detected: list[dict], ocr_static: list[dict], duration: float) -> list[dict]`
  - Unions OCR static fragments that overlap (IoU>0.3 or containment>0.5) and folds them into an overlapping detected box.
  - Output regions have `kind='static', auto=True, confirmed=False, enabled=True` and `label` `"Chữ cố định"` when OCR text is present, else `"Logo"`. `text` is the most common OCR text.
- `apply_candidates(existing: list[dict], candidates: list[dict]) -> list[dict]`
  - Keeps every non-static region, every confirmed region and every non-auto static region.
  - Drops the OCR static fragments that were merged and the old unconfirmed auto candidates.
  - Does not add a candidate that overlaps (IoU>0.5) a confirmed or rejected region.

**Algorithm (pinned values):**
- Sample one frame every 2 s, at most 150 frames, downscaled to width 640.
- Edge = Sobel magnitude > 40.
- Persistence = mean edge occupancy per pixel. Candidate pixels: persistence ≥ 0.5.
- Morphological close 5×5, then connected components.
  - Keep area between 0.0003 and 0.06 of the frame.
  - Pad the bbox by 6 source px.
- Background check: the ring of 12 px around the bbox must have a mean temporal std ≥ 6 (grey levels). Otherwise drop it as a still shot.
- Presence per sample: edge overlap with the component mask ≥ 0.5.
  - Runs are merged when the gap is ≤ 2 samples. Start/end are widened by 1 s and clipped.
  - Presence ≥ 0.8 of the samples → `start=0, end=duration`.
- Exclude a candidate whose box overlaps an `exclude` box by > 50% of its own area.

### Task 2: Erase static regions with the 6.2 eraser (backend)

**Files:**
- Modify: `backend/dubflow/engine_cli.py` (`erase`), `backend/dubflow/pipeline.py` (`erase_subtitles`, `erase_current`, `ERASE_VERSION`, render mask selection), `backend/dubflow/app.py` (GET regions marks `erased`)
- Test: `backend/tests/test_subtitle_erase.py` or a new `test_static_erase.py` (OCR venv), plus `backend/tests/test_pipeline*.py` (backend venv)

**Interfaces:**
- Consumes: regions with `kind='static', enabled=True` (from Task 1 and from drawn boxes).
- Produces:
  - the erase request gains `static_regions: [{id,x,y,width,height,start,end}]`;
  - erase.json gains `static_hash` (sha256 of the sorted geometry/time list) and `static_ids`;
  - `ERASE_VERSION = 6`;
  - GET `/api/jobs/{id}/regions` adds `erased: true` to static regions whose id is in `static_ids` when `erase_current` holds.

**Behavior:**
- For each frame inside a static region's [start, end], the mask is the full rectangle, unioned with the subtitle glyph mask when both apply.
- Use the same `erase_frame` / LaMa path and the same static-ref reuse.
- `clean.mp4` is produced when there are subtitle segments OR enabled static regions.
- `erase_current` is false when `static_hash` differs.
- Render with `use_clean`: drop static regions whose id is in `static_ids` from the ffmpeg mask filters. Transient regions are unchanged.
